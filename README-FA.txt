بسته اصلاح فایل‌های پروژه سفارش‌یار

این بسته شامل فایل‌های جایگزین برای اصلاح خطاهای قطعی مشاهده‌شده در مخزن است:
- اصلاح AndroidManifest و تعریف درست صفحه آغازین
- بازنویسی MainActivity
- بازنویسی Database با ساختار هماهنگ سفارش، اقلام و پرداخت‌ها
- پاک‌سازی صفحه‌های کالا، مشتری و پرداخت
- افزودن styles.xml در مسیر صحیح
- افزودن GitHub Actions در مسیر استاندارد .github/workflows

روش استفاده:
محتویات ZIP را در ریشه مخزن Sefareshgir استخراج و فایل‌ها را با همین مسیرها جایگزین کن؛ سپس تغییرات را commit/push کن.
بعد از push، در GitHub وارد Actions شو و اجرای Build Sefareshyar APK را باز کن. فایل APK از بخش Artifacts قابل دریافت خواهد بود.

نکته: این بسته سورس اصلاح‌شده است، نه APK تست‌شده. در محیط فعلی امکان ثبت مستقیم تغییرات در مخزن یا اجرای Android SDK وجود نداشت.
